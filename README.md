## 🚀 Key Features

### 🧠 Multi-Vector Assessment Modes
- **Algorithms & Data Structures**: Solve real-world algorithmic problems in an embedded Monaco IDE with automated syntax highlighting, keyboard shortcuts, and code evaluation.
- **Distributed System Design**: Architecture simulations covering horizontal scaling, message queues, consensus protocols, caching layers, and database sharding.
- **Staff Behavioral Leadership (STAR)**: Evaluates high-stakes incident post-mortems, team conflict resolution, and architectural trade-off justification using the STAR methodology.

### 🎙️ Native Speech Recognition & Hands-Free Audio
- Live voice-to-text response capture via Web Speech API with real-time waveform visualizers and confidence meters.
- Vocal mode mimics high-pressure phone/video screen interviews for realistic delivery practice.

### ⚡ Sub-Second AI Coaching & "Caveman Direct" Diagnostics
- Dual-tier feedback model:
  - **Executive Architectural Analysis**: Nuanced critique of code performance, edge case coverage, and system trade-offs.
  - **Caveman Direct Summary**: High-speed, blunt, zero-fluff summary highlighting exact wins and critical fixes.

### 📄 Contextual Resume Grounding
- Upload your PDF resume to parse technical stacks, career milestones, and project ownership.
- The AI dynamically tailors questions and difficulty calibrations (L3 Junior to L6+ Staff/Principal) to match your real-world background.

### 🛡️ Enterprise Anti-Cheat & Session Guardian
- Audio focus detection and tab-blur monitors track unauthorized window switching.
- Heuristic clipboard monitoring detects suspicious bulk-paste operations during technical evaluations.

### 📊 PDF Export & History Archive
- Every completed session is preserved with full question logs, candidate answers, and AI scores.
- Export polished, recruiter-ready PDF performance certificates and diagnostic reports.
